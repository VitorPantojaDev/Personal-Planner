Mural de Avisos, Recados e Sugestões

Este espaço serve para que os usuários e o moderador possam se comunicar.
Sinta-se à vontade para sugerir melhorias, pedir novas funcionalidades, avisar de bugs, etc.
De tempos em tempos o moderador pode colocar avisos aqui.
Para facilitar a comunicação, cada usuário só pode publicar uma mensagem por vez.
Os recados aqui são visíveis para todos para evitar duas sugestões iguais.
